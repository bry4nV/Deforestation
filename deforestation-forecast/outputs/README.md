# Outputs

Artefactos consolidados que no forman parte directa de `data/raw` ni de
`data/interim`.

- `logs/`: registros de ejecucion de los pipelines.
- `figures/`: figuras auxiliares o exploratorias.
- `debug/`: salidas temporales usadas para revisar corridas puntuales.

Los resultados metodologicos por objetivo siguen viviendo en `data/interim/O*`.
